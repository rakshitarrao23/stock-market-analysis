
# 📈 Stock Market Analysis Dashboard

## Overview
An interactive dashboard for exploring historical stock prices, trading volume, daily returns, and market trends using Python.

## Features
- Select stocks such as Apple (AAPL) and Reliance Industries (RELIANCE.NS)
- Analyze different historical time periods
- View latest, highest, and lowest closing prices
- Visualize historical closing prices
- Compare closing prices with 20-day and 50-day moving averages
- Analyze daily stock returns
- Explore historical trading volume
- View recent stock data

## Technologies Used
- Python
- Pandas
- NumPy
- yfinance
- Plotly
- Streamlit

## Installation

1. Clone or download this repository.
2. Install the required libraries:

   `python -m pip install -r requirements.txt`

3. Run the dashboard:

   `python -m streamlit run app.py`

4. Open the local URL displayed in the terminal.
